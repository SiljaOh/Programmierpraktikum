Git-Grundlagen:

Anfang erstmal clonen

in Ordner gehen und dann 

git clone https://gitlab2.cip.ifi.lmu.de/grossla/progprakt-17.git

cd progprakt-17


Aktueller Stand:

git pull origin main


evtll neuer Ordner :

mkdir Blatt1


Datei hinzufügen:

touch script1.py (erstellen)

git add script1.py


Datei ändern: 

echo "# erstes Skript: ..." > script1.py

nano script1.py

mit add wieder hinzufügen


Änderung ansagen:

git commit -m "Erste Version Abgabe1"


Änderungen speichern/mit allen teilen:

git push origin main
